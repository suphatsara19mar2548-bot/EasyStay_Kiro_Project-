# EasyStay – Simple Room Booking Website

## วิธีเปิดใช้งาน
1. แตกไฟล์ ZIP
2. เปิดโฟลเดอร์ EasyStay_Project ด้วย Kiro
3. เปิดไฟล์ index.html ในเบราว์เซอร์ (หรือใช้ส่วนขยาย Live Server)
4. ทดลองเลือกห้อง เลือกวันเข้าพัก และกรอกข้อมูลจอง

## ไฟล์ในโปรเจกต์
- index.html: โครงสร้างหน้าเว็บ
- style.css: รูปแบบและการจัดหน้า รองรับมือถือ
- script.js: เลือกห้อง คำนวณราคา ตรวจสอบวัน และแสดงสรุปการจอง

## Prompt สำหรับใช้กับ Kiro
สร้างและปรับปรุงเว็บไซต์จองห้องพักชื่อ EasyStay โดยใช้ HTML, CSS และ JavaScript แบบไม่ใช้ framework
เว็บไซต์ต้องเป็นภาษาไทย รองรับมือถือ มีหน้าแสดงห้องพัก 3 ประเภท (Standard, Deluxe, Family)
ผู้ใช้เลือกห้อง วันเช็กอิน วันเช็กเอาต์ กรอกชื่อและเบอร์โทรศัพท์ได้
ระบบคำนวณจำนวนคืนและราคารวม ตรวจสอบว่าวันเช็กเอาต์อยู่หลังวันเช็กอิน
และแสดงสรุปคำขอจองบนหน้าเว็บ ใช้ดีไซน์สะอาดตา โทนสีเขียวธรรมชาติและครีม
แยกโค้ดเป็น index.html, style.css และ script.js

## ข้อจำกัด
นี่เป็นต้นแบบเพื่อการศึกษา ยังไม่มีระบบหลังบ้าน ฐานข้อมูล การยืนยันตัวตน หรือการชำระเงินจริง
ข้อมูลการจองจะแสดงบนหน้าเว็บเท่านั้นและไม่ถูกบันทึกถาวร
